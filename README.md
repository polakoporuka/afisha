# Афиша матча — локальный генератор

Инструмент собирает афиши двух типов (анонс матча и итоговый счёт) в двух форматах
(1:1 1080×1080 и 9:16 1080×1920) на русском и сербском языках и экспортирует готовые PNG.
Работает полностью локально, без интернета, без установки и без генеративного ИИ:
вёрстка, шрифты и фоны перенесены из PSD-шаблонов и рисуются на Canvas.

## Как пользоваться

1. Откройте `index.html` в браузере (Chrome, Edge, Firefox, Safari).
   Для телефона удобнее файл `dist/afisha.html` — это та же программа, но одним файлом,
   его можно переслать себе в мессенджер и открыть в браузере.
2. Выберите тип поста (**Анонс** / **Счёт**). В анонсе есть выбор заголовка:
   **Следующий матч** («СЛЕДУЮЩИЙ МАТЧ» / «SLEDEĆA UTAKMICA») или **Товарищеский**
   («ТОВАРИЩЕСКИЙ МАТЧ» / «PRIJATELJSKA UTAKMICA»). При открытии всегда стоит «Следующий матч».
3. Выберите команды слева (хозяева, по умолчанию ФК Миляковац) и справа. Кнопка «⇄ поменять»
   меняет их местами. Пункт «своя команда (разово)» позволяет ввести название и загрузить
   логотип, не сохраняя его в базу; сербское написание подставится само.
4. Для анонса укажите дату в календаре, время (часы и минуты списками, всегда 24 часа) и стадион.
   Всё вводится один раз по-русски. Строка даты («27 сентября» / «27. septembar») и слово
   «Стадион» / «Stadion» формируются сами для обоих языков.
5. Для итогового счёта введите голы.
6. Кнопка **«Скачать ZIP: RU + SR, 1:1 + 9:16»** отдаёт архив с четырьмя готовыми картинками.
   Под ней четыре маленькие кнопки, если нужна одна картинка.
7. Переключатель **«Предпросмотр: RU / SR»** над превью только показывает, как выглядит сербская
   версия. Отдельно её заполнять не нужно, в ZIP попадают обе.

### Стадион

Стадион вводится по-русски, без слова «стадион». Под полем серой строкой показано сербское
написание, оно транслитерируется автоматически (Миляковац → Miljakovac, Хайдук → Hajduk).
Если автоматика ошиблась, нажмите карандаш ✎ рядом и поправьте; «↺ авто» возвращает
автоматический вариант. Инструмент запоминает введённые стадионы вместе с командой хозяев:
в следующий раз при выборе тех же хозяев стадион подставится сам, а при вводе поле предлагает
подсказки из уже использованных названий. Отдельный список стадионов вести не нужно.

### Расширенные настройки

Галочка «Расширенные настройки» (при открытии всегда выключена) раскрывает:

* сдвиг логотипов влево-вправо, отдельно для 1:1 и 9:16: тащите логотип на превью или
  двигайте ползунок. Логотипы всегда одной высоты и выровнены между собой и с текстом, по
  вертикали и по размеру они не меняются. Название команды едет вместе с логотипом, размер
  шрифта не меняется. «Сбросить сдвиги» возвращает автоматическое размещение;
* показ на превью 9:16 зоны 4:5 (1080×1350), которую показывает лента Instagram, и квадрата
  1:1. В экспорт разметка не попадает. Весь информационный блок вертикальной афиши укладывается
  в зону 4:5 с запасом.

### База команд

Раздел «База команд» внизу панели. Встроенные команды берутся из `teams.json` при сборке.
Добавленные через интерфейс команды сохраняются в браузере (localStorage) на этом устройстве.
Чтобы команда была на всех устройствах, добавьте её в `teams.json` и пересоберите (см. ниже).

Встроенные команды сезона: FK Miljakovac, City Sport Klub, FK Hajduk, FK Palilulac,
FK Omladinac 1961, FK PKB Kovilovo, FK Resnik.

## Структура папки

```
tool/
  index.html            интерфейс
  css/style.css         стили интерфейса
  js/app.js             логика: разметка форматов, текстовый движок, экспорт
  teams.json            исходная база команд (для сборки)
  assets/
    data.js             ВСЕ ресурсы в одном файле (шрифты, фоны, логотипы в base64) — генерируется
    teams_custom.js     (необязательно) пользовательская база команд
    fonts/              Kino-Regular.otf, Maler.ttf
    bg/                 фоны: next_1x1, next_9x16, score_1x1, score_9x16
    logos/              логотипы команд (PNG с прозрачностью)
  build_assets.py       сборщик assets/data.js и dist/afisha.html
  dist/afisha.html      всё в одном файле (для телефона / пересылки)
```

Ресурсы встроены в `data.js` в base64 намеренно: браузеры запрещают экспорт PNG с холста, на
который нарисованы картинки, открытые по `file://` как отдельные файлы. Со встроенными данными
экспорт работает с диска без всяких серверов и флагов.

## Как добавить много команд сразу или заменить фон

1. Положите логотипы в `assets/logos/` (PNG с прозрачностью, желательно 500–1000 px по большей стороне).
2. Допишите команды в `teams.json` (поля: `id`, `ru`, `sr`, `logo`, `stadium_ru`, `stadium_sr`).
3. Запустите `python build_assets.py` (нужен только Python 3, без библиотек).
   Скрипт перегенерирует `assets/data.js` и `dist/afisha.html`.

Фоны лежат в `assets/bg/` и вырезаны из PSD без текста и логотипов. Если поменяете фон,
сохраните его под тем же именем и размером и снова запустите сборку.

## Правила вёрстки (что делает автоматика)

* **Заголовок** («СЛЕДУЮЩИЙ МАТЧ», «SLEDEĆA UTAKMICA», «РЕЗУЛЬТАТ МАТЧА», «REZULTAT UTAKMICE»):
  размеры, базовые линии, трекинг, наклон и зелёная обводка «только снаружи» сняты с PSD отдельно
  для каждого языка.
* **Логотипы** обрезаются по прозрачным полям и приводятся к одной высоте 298 px (в 1:1-анонсе
  251 px), ширина по пропорциям, центр по колонке. Поэтому файлы логотипов могут быть с любыми
  полями и любого размера, лучше 500 px и больше.
* **Названия команд** (шрифт Maler, капителью): если строка не помещается в колонку, название
  переносится на две строки по словам; если и так не помещается, уменьшается размер (до 62 %).
  Блок центрируется относительно опорной точки, как в шаблоне.
* **Время, дата, стадион, счёт** центрируются и при необходимости ужимаются по ширине.
* **Сербская диакритика.** Шрифт Maler не содержит Č Ć Š Ž Đ, поэтому инструмент рисует базовую
  букву и дорисовывает знак сверху (или перекладину у Đ). В шрифте Kino все эти буквы есть.
* **1:1-анонс** в исходном PSD был 9:16-макетом, вписанным в квадрат; здесь он воспроизведён
  таким же (масштаб 0.843, обрезка сверху и снизу), поэтому пропорции совпадают с оригиналом.

## Ссылки-параметры

Состояние можно задать через параметры URL, например для быстрого шаблона:

```
index.html?type=next&L=miljakovac&R=hajduk&date=2026-05-17&time=17:00&stadium=ФК%20Миляковац
index.html?type=next&headline=friendly&lang=sr&L=miljakovac&R=resnik
index.html?type=score&L=miljakovac&R=palilulac&score=7:0
```

`lang` задаёт язык предпросмотра, `stadium` — стадион по-русски, `stadiumSr` — сербское написание вручную.
Параметр `qa=1x1` или `qa=9x16` показывает один холст в натуральную величину без панели.

## Хостинг на GitHub Pages

Папка `tool/` — это git-репозиторий, а в `.github/workflows/deploy.yml` лежит сценарий,
который при каждом изменении в ветке `main` сам запускает `build_assets.py` и публикует
результат на GitHub Pages. Адрес сайта: `https://<логин>.github.io/<репозиторий>/`.
Одиночный файл для телефона доступен по адресу `.../dist/afisha.html`.

Как редактировать прямо в интернете:

1. Логотип: на сайте GitHub откройте папку `assets/logos`, нажмите «Add file → Upload files»,
   перетащите PNG и нажмите «Commit changes».
2. Команда: откройте `teams.json`, нажмите карандаш, допишите запись по образцу соседних,
   нажмите «Commit changes». Через минуту-две сайт пересоберётся сам (вкладка Actions
   показывает ход сборки).
3. Фон: так же замените файл в `assets/bg/` под тем же именем.

Файлы `assets/data.js` и `dist/` в репозиторий не попадают, они собираются автоматически.
При работе с диска их по-прежнему создаёт `python build_assets.py`.
