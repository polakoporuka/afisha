Общая база команд: ключ GitHub и общий пароль

Эта страница работает только у вас в браузере: ключ и пароль никуда не отправляются, кроме одной проверки ключа на api.github.com. На выходе получится файл vault.json с зашифрованным ключом. Его нужно положить в папку assets/ и отправить в репозиторий.

  1. Создайте ключ: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → выбрать afisha.
  3. Permissions → Repository permissions → Contents: Read and write. Больше ничего.
  4. Expiration: максимум (год). Скопируйте ключ, он начинается с github_pat_.
